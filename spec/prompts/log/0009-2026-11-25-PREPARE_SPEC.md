## Prompt

```text
# Úloha 0009: change experiment – jednoduché UI pre FR1

Mode: PREPARE_SPEC

Rozhodol: Martin Štefanko (Software architect). Mením rozhodnutie DR-17 („UI nie je v rozsahu prototypu“):
- Prototyp bude mať jednoduché UI pre ROLE-SpravcaNavstev na vytvorenie rezervácie (FR1).
- UI = jedna statická stránka (HTML + vanilla JavaScript) servírovaná tou istou ASP.NET aplikáciou (wwwroot), bez nového NuGet balíka a bez frontend buildu.
- Prihlásenie: používateľ vloží JWT token vydaný cez dotnet user-jwts (DR-23 platí ďalej, login endpoint ostáva mimo rozsahu).
- Klient sa zadá ako UUID (DR-24 platí ďalej); pole je predvyplnené seed klientom.
- Používateľ zadá dátum a čas v miestnom čase Europe/Bratislava; UI ho prepočíta na UTC s „Z“ (DR-18, DR-C03).
- UI zobrazí potvrdenie pri 201 a zrozumiteľnú slovenskú hlášku pre každý typ problému z contractu.
- Sumarizácia pred uložením (DR-17) ostáva mimo rozsahu.
- API contract API-Reservations 0.2.1 sa NEMENÍ; UI je iba jeho konzument.

Úloha:
1. Vytvor draft ADR-010 (Proposed) pre technológiu UI a zmenu DR-17.
2. Navrhni nový requirement pre UI (draft) s väzbou na FR1, ROLE-SpravcaNavstev a AS-SpravaRezervaciiAKlientov.
   Over v podkladoch (views B-01), či model obsahuje Application Interface pre recepčnú; ak nie, označ to ako otvorenú otázku
   (model v Sparx EA doplním ja), nevymýšľaj prvok.
3. Priprav draft user story US-002 a Gherkin scenáre v business jazyku (úspešné vytvorenie cez UI, zobrazenie dôvodu odmietnutia,
   prepočet miestneho času) – bez opisu klikania na konkrétne tlačidlá.
4. Navrhni úpravy deployment.yaml / technology-context.yaml (UI je súčasťou ART-SoftverIntelliWell) a vyrieš pri tom aj odložené
   nálezy N-01, N-02, N-10 (scenár pre token bez sub), I-04 a traceability FR1 → kód → testy – ako návrh na moje schválenie.
5. Approved súbory nemeň priamo: nové drafty a navrhované zmeny ulož do spec/drafts/ s jasným popisom, kam patria.
6. Aktualizuj open-decisions.md. Log podľa CLAUDE.md (0009-…-PREPARE_SPEC.md). Necommituj.
Na konci vypíš DECISION REQUIRED, ak vzniknú.
```
